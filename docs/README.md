## Agreed boundaries

- Public curricula and lesson content; public practice questions, correct answers and explanations; suggested evaluation guides.
- No OWC-run certification exams, private official question pools, provider approval scheme, gradebook, proctoring, or credential issuance.
- Contributors may use GitHub or a future plain-language portal editor. Only reviewed changes reach published content.
- Adopters remain responsible for contextualizing policies, making their own tests, and meeting any applicable compliance obligations.
- The initial subjects are Responsible AI at Work, Cybersecurity Awareness and Data Privacy Essentials, all currently **planning/draft**.
