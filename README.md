# Open Workplace Commons — Curricula

**Open knowledge. Better workplaces.**

This repository is intended to become the source of truth for **open, community-maintained workplace curricula, learning resources, public practice questions with answers, and nonbinding evaluation guidelines**.

- **OWC is not a certification or examination authority.** Organizations decide how to deliver training, evaluate learners, record results and issue any completion certificates.
- **Any compatible provider can use OWC material.** The OWC portal, Anecdote, Quizdemics and LMS Grid are optional; Moodle, Canvas, H5P, Xerte, Articulate and custom tools must be equally able to use the published content through suitable adapters.
- **The specification is draft.** The accompanying design pages describe a proposed v0.1 content model and review workflow, not a ratified standard or a claim of conformance.

## Design documents

Start with the [documentation index](docs/README.md), then review [the principles](docs/01-principles.md), [the content model](docs/02-content-model.md), and [the interoperability approach](docs/04-interoperability.md).

The [example course](examples/responsible-ai/course.yaml) illustrates concepts only; it has not undergone subject-matter review. A future content license and contributor policy must be ratified before third-party content publication.
